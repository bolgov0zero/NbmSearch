# NbmSearch

Локальный поисковик по файлам с веб-интерфейсом. Индексирует `.docx`, `.xlsx`, `.pdf`, `.txt` и позволяет искать по содержимому через браузер — с выбором папок, сниппетами и подсветкой.

## Быстрый старт — launcher.bat

1. Убедитесь, что установлен [Python 3.11+](https://www.python.org/downloads/)
2. Дважды кликните `launcher.bat`
3. Браузер откроется автоматически на `http://localhost:8080`

При первом запуске автоматически установятся все зависимости.

## Быстрый старт — скачать .exe

1. Перейдите в раздел [Releases](../../releases)
2. Скачайте `NbmSearch-windows.exe` из последнего релиза
3. Запустите — сервер поднимается автоматически

## Настройка папок — config.py

Откройте `app/config.py` и укажите папки для индексации:

```python
SEARCH_FOLDERS = [
    {"name": "Документы",  "path": "C:/Files"},
    {"name": "Архив",      "path": "D:/Archive"},
    {"name": "Проекты",    "path": "D:/Projects"},
]

PORT = 8080                    # порт веб-сервера
DB_PATH = "file_index.db"     # путь к базе данных
REINDEX_INTERVAL_MINUTES = 60 # интервал полной переиндексации
MAX_WORKERS = 4                # потоков для параллельной обработки
```

Каждая папка задаётся словарём с двумя полями:
- `name` — отображаемое имя (используется для фильтрации в поиске)
- `path` — путь к папке на диске

## Поиск

- Откройте `http://localhost:8080`
- Введите запрос
- Выберите где искать: **Везде**, в одной или нескольких папках (кликабельные чипы под строкой поиска)
- Результаты показываются с текстовым сниппетом и подсветкой найденного слова

## Панель администратора

`http://localhost:8080/admin`

- Количество файлов по каждой папке
- Время последней и следующей переиндексации
- Кнопка ручного запуска переиндексации
- Список последних 20 проиндексированных файлов

## Доступ из локальной сети

Сервер слушает на `0.0.0.0`, поэтому доступен с любого устройства в сети:

```
http://<IP-адрес-компьютера>:8080
```

IP-адрес можно узнать командой `ipconfig` в терминале Windows.

## Поддерживаемые форматы

| Формат | Библиотека     |
|--------|---------------|
| `.docx`| python-docx   |
| `.xlsx`| openpyxl      |
| `.pdf` | pdfplumber    |
| `.txt` | встроенный    |

## Перезапуск сервера

В админке (`/admin`, блок «Перезапуск сервера») можно настроить автоматический перезапуск — настройки хранятся в основной БД и применяются сразу, без рестарта:

- **По расписанию** — дни недели и время (например, пн, ср, вс в 03:00). Если в этот момент идёт индексация, перезапуск дождётся её окончания, но не дольше заданного срока.
- **По потреблению памяти** — мягкий порог (перезапуск, когда память выше порога около минуты, нет индексации и, если включено, идёт разрешённое окно времени) и аварийный порог (перезапуск сразу).
- Защита от циклов: не чаще одного автоматического перезапуска в 15 минут и не больше трёх «по памяти» в час.

Работает только в собранном exe (нужен `NbmSearchUpdater.exe` рядом с `NbmSearch.exe`). Последние перезапуски с причиной видны в том же блоке.

## Лог

Сервер пишет в `nbmsearch.log` рядом с exe. Записи старше 30 суток удаляются: при каждом запуске (уже существующий файл урезается) и затем раз в сутки.

## Ограничения индексации (settings.json)

| Ключ | По умолчанию | Назначение |
|------|--------------|------------|
| `max_workers` | 4 | потоков индексации (watchdog использует половину) |
| `heavy_workers` | 1 | одновременно разбираемых pdf/xls/xlsx |
| `max_file_mb` | 64 | файлы больше (кроме txt/csv) индексируются только по имени, `0` — без лимита |
| `max_text_chars` | 20 000 000 | предел текста, извлекаемого из одного файла |

Одна и та же папка не индексируется двумя запусками одновременно, а фоновые задачи (переиндексация, watchdog) выполняет только один процесс — при втором экземпляре он ждёт завершения первого (`nbmsearch.lock`).
